# layerflow-releases

Public binary distribution for the LayerFlow CLI (`lf`).

The LayerFlow **source stays private** — this repository only hosts prebuilt
release binaries generated by GoReleaser.

## Install (macOS / Linux)

```bash
curl -fsSL https://raw.githubusercontent.com/Rohit94r/layerflow-releases/main/install.sh | bash
```

That one-liner:

1. Detects your OS and architecture
2. Finds the latest release on this repo
3. Downloads the matching `lf` binary and verifies its SHA-256 checksum
4. Installs it to `~/.local/bin/lf`

Check it works:

```bash
lf --version
lf --help
```

### Install a specific version

```bash
VERSION=v0.1.0 curl -fsSL https://raw.githubusercontent.com/Rohit94r/layerflow-releases/main/install.sh | bash
```

### Windows

Run the installer from WSL, or download the `.zip` from the
[latest release](https://github.com/Rohit94r/layerflow-releases/releases/latest).

## How releases get here

Tagging the private `Rohit94r/LayerFlow.In` repo with `v*` triggers a GitHub
Actions workflow that runs GoReleaser. GoReleaser builds every OS/arch, and
uploads the archives + `checksums.txt` to a GitHub Release **in this repo**:

```bash
git tag v0.1.0
git push origin v0.1.0   # private repo — release lands here automatically
```

## Security

- No source code is published here.
- Every archive ships with a SHA-256 checksum (`checksums.txt`) that the
  installer verifies before installing.
- The release token is a fine-grained GitHub token scoped to **only** this repo
  (`contents: write`), stored as `GH_TOKEN` on the private repo.
